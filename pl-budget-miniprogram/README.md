# 项目预算损益表 PL 系统 · 微信小程序版

把已经验证过的单文件 HTML 版 PL 系统（v33/v36 口径）完整移植为微信小程序，方便在手机端随时做项目预算与报价测算。计算结果与 Excel 口径完全一致，已用示例数据验证通过。

## 一、怎么跑起来

打开微信开发者工具，选择「导入项目」，目录指向本文件夹 `pl-budget-miniprogram`。

当前 `project.config.json` 里用的是测试 AppID `touristappid`，可以直接用游客模式预览。要真机调试或正式发布，需替换为你自己的小程序 AppID（在微信公众平台后台获取）。

导入后点「编译」，即可在模拟器里看到完整的损益测算界面。

## 二、功能范围

界面与 HTML 版一一对应，移动端暗色主题、rpx 自适应：

项目信息录入（客户、销售、售前、有效期）
子项管理（可增删多个子项，每个子项含人员排期、委外/硬件软件/第三方实施/其他成本、实际合同金额）
固定费用（软件类、第三方类两段式录入）
市场拓展管理费、项目管理费（悦报销口径）
收款信息与项目费用合计
项目总览（4 张卡片 + 各子项毛利率卡片）
净订单毛利率标准对照
项目损益总表（含软件/服务毛利、硬件毛利、固定费用、最终净订单毛利率）

所有输入改动后点「重新计算」即可刷新全部结果；也内置「一键填充示例数据」方便快速看效果。

## 三、导出说明（重要）

小程序运行环境没有 DOM，也没有 openpyxl，因此无法直接回填你电脑里的 Excel 模板。我们提供了两种稳妥的导出方式：

导出 PL 表（.xls）：生成 SpreadsheetML 2003 格式，手机端微信用 Excel/WPS 可直接打开查看，含完整项目信息与损益总表。

导出报价单（.xls）：生成给客户看的正式报价单，含子项推荐合同金额、净订单毛利率、整体合计。

复制 JSON：把当前所有录入数据复制为 JSON 到剪贴板，最稳妥，可交后端或电脑端据此生成正式 Excel 模板。

如果你确实需要「在小程序里一键导出成你们现有 Excel 模板的 .xlsx」，那条路需要配一个云函数（云开发或自有后端跑 openpyxl），把 JSON 传过去由服务端填模板再回传文件。当前版本先以 .xls 预览 + JSON 复制覆盖手机端最常用的场景。

## 四、计算口径（与 Excel 一致）

净订单毛利率 = 项目净订单毛利润 ÷ 净订单（净值），不扣悦报销类费用。
固定费用按软件类成本 : 第三方类成本的比例分摊到各子项。
每个子项的推荐合同金额按目标毛利率反算：成本 ÷ (1 − 目标毛利率) 再还原含税。
录入实际合同金额时优先使用实际值，并在损益总表按推荐收入比例缩放 SW/TP。
人员成本 = 人天单价 × 人天 ÷ 20.67（月均工作人天）。

示例数据验证结果：成本 ¥316,483、收入 ¥575,424、合同 ¥609,950、净订单毛利率 45.00%，与预期完全一致。

## 五、目录结构

```
pl-budget-miniprogram/
├── app.js / app.json / app.wxss      全局入口、配置、暗色主题
├── project.config.json               项目配置（AppID 需替换）
├── sitemap.json
├── pages/index/                      单页面：wxml 结构 + wxss 样式 + js 逻辑 + json 配置
└── utils/
    ├── calc.js                       纯函数计算引擎（口径核心，与视图解耦）
    ├── constants.js                  业务类型与角色常量
    └── export.js                     导出 PL 表 / 报价单 / JSON
```
